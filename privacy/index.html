Privacy Policy

MAP Publisher · Effective 6 October 2026

This policy describes what MAP Publisher, an internal tool operated by Moment Art Production (Jeddah), actually does with data. It runs on the operator's own computer and has no server of its own that receives your data.

1. Whose data

MAP Publisher handles data about the social media accounts it is connected to, which are accounts the operator owns or is authorised to manage. It collects nothing from visitors of this website: the pages are static, set no cookies and run no analytics or advertising scripts of their own. The company that hosts these pages may keep ordinary server logs, which are outside our control.

2. What it receives from TikTok

When the operator authorises a TikTok account through TikTok Login Kit, TikTok provides the following, limited to the permissions granted:

TikTok permissionData
user.info.basicopen ID (TikTok's identifier for the account), display name, avatar link
user.info.profileusername, profile link, bio, verified status
user.info.statsfollower, following, like and video counts
video.listthe account's public videos (identifier, title, cover image link)
video.upload, video.publishno data is read; these only allow creating a draft or posting a video, and each such action needs a separate human approval

TikTok also returns an access token (valid for about 24 hours) and a refresh token (valid for about 365 days, per TikTok), with the list of permissions granted and their expiry times.

3. What is stored, and where

  • Credential files on the operator's computer: the account's tokens, open ID, granted permissions and expiry times, in a folder that is excluded from version control and set to be readable only by the operator where the file system supports it. The TikTok app's client key and secret are stored the same way, once for all accounts. Credentials are never written to logs, to the database or to screen output.
  • A local database (SQLite) on the same computer: the account's handle, display name and open ID, connection status, the result and time of identity checks, the permissions TikTok reported, and an activity and audit log of what the tool did and when.
  • Not stored by the current version: video lists and statistics read from TikTok are shown to the operator when requested and are not saved to the database.
  • Point-in-time copies of the local database, without credential files, may be kept in a backups folder on the operator's computer before significant changes.

4. How it is used

Only to confirm which TikTok account is connected, to show connection status on the operator's local dashboard, to show the operator account information on request, and to carry out an action the operator has specifically approved. It is not used for advertising, profiling or analytics, and it is not sold, rented or shared with anyone. Data travels only between the operator's computer and TikTok.

5. Retention

  • Tokens are kept while the account stays connected. The access token is replaced when it is refreshed, and a new refresh token replaces the old one if TikTok issues one.
  • Database records and audit log entries are kept until the operator deletes them. There is no automatic deletion schedule.

6. Disconnecting and deletion

  • Disconnect: the tool's disconnect command asks TikTok to revoke the access and deletes the stored credential file. The account holder can also remove the app's access in TikTok's own app-permission settings at any time.
  • Deletion: the credential file is removed on disconnect. Earlier database records (such as past identity checks and audit log entries) stay until the operator deletes them from the local database, which the operator can do on request. Deletion of local data is carried out by the operator by hand; there is no automated request process.
  • Data held by TikTok itself is governed by TikTok's own privacy policy.

7. Security

Credentials are entered through hidden prompts, kept out of version control, and never printed. No system is perfectly secure, and we make no guarantee beyond these practices.
